# and what it answers instead. One line per program: the path, a tab, and text
# the route's output contains. tests/wasm_engine.rs reads this, holds each listed
# program to its answer, and fails on a listed program that has started agreeing
# with native: a closed gap left on the list is a lie about the route.

# and no filesystem, so each of these is the runtime's own refusal of a call the
# host could not serve.
