# that deferral differently: native and the oracle keep a cell nobody has
# demanded and say `<thunk>`, where the browser keeps the closure that would
# answer it and says `<fn>`. Both are honest about having no value yet; they
# do not use the same word for it. Closing this means teaching the renderer to
# ask a deferral what it is, which reaches into the interpreter's own render.

# the browser keeps the closure that would answer the field and says `<fn>`,
# where native and the oracle hold a cell and print the record behind it.
#
# The same difference as a_constant_that_holds_itself above, and it closes
# with gavel 20b's render-forcing rather than with a blackhole: the browser
# has a deferral here, it just prints the wrapper instead of asking it.
