senro guides

the guides

each guide covers one part of senro, with code taken from the apps senro is built against. a panel titled with a file's path shows that file as senro's repository holds it; the site's build checks every such panel against the commit it names, so the code here is the code that runs.

  • getting started

    build the guestbook one file at a time: the schema, a model, the actions and a view, then run it against Postgres.

  • models and migrations

    where the schema comes from, how a model is checked against its table, and the policies and rules that guard each write.

  • views and components

    kata templates, layouts, components whose actions run in the browser or on the server, and pages rendered in the browser from data.

  • routing

    how an action's name places it: the seven actions, ids, singular resources, naming a route from code, and keeping an old URL.

  • sessions and sign-in

    the signed session, making an account, how passwords are kept, signing in without saying which names exist, limiting attempts, pages that ask for a sign-in, sending mail, resetting a lost password, confirming an address, and refusing requests from other sites.
