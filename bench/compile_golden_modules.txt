# What compiling a module costs: an entry, a local module beside it, and the
# standard library each pulls in. Every sample in compile_golden.txt is a
# single file with no imports, which leaves the loader, enrollment and
# qualification unmeasured there.
#
# `loads` counts the modules the compile compiled. `shared` imports two local
# modules that both import a third, and all three import std/text, so a
# loader that compiles a module once per import reads as more loads than
# modules (kanso#2373). `apart` is three modules that each import std/text
# and bring words of their own (kanso#2434). `lent` uses std/list on either
# side of a module that slices a text. std/text spells `span`, which is also
# a helper of the list library's sort, and does not import std/list: a word
# keeps a declaration of a module its own module imports and of no other, so
# std/list is compiled once (kanso#2442).
#
# Kept apart from that file because the welfare index sums its rows, and a
# sample added there would read as a regression the size of the sample.
