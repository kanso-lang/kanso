# Retired instructions for `kanso play startup_corpus/main.kso`, counted under
# callgrind and anchored at the `kanso::main` frame.
#
# The other three compile rows count what compiling a body of code costs:
# compile_instructions a directory, entry_instructions a file with statements,
# library_instructions a file of definitions. All three run `kanso check`,
# which stops before codegen. This one runs `kanso play` on a program holding
# a single `print`, so it counts what a run costs before it has any work to
# do: the loader, the prelude, and the backend deciding what to emit for
# almost nothing.
#
# Start-up belongs to the development side of the objective, ruled 2026-09-16:
# `kanso test` pays it on every invocation and production never pays it once.
#
# One row, one value, ruled 2026-09-05: no per-chip key and no pinned pair. A
# build that counts two numbers is a reproduction failure to hunt, and the
# `startup_binary sha256` and `startup_sample` lines the gate prints are where
# the hunt starts. The row is CI's, never a container's.
#
# A rise is a regression to explain and a fall is a win to bank: say which in
# design/compiler-log.md, which holds the history of every move.
