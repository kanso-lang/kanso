# Allocator counters for the wide-array print, the shape none of the four
# benchmarks beside it has. They carry deeply nested documents whose widest
# array holds ten elements, and they render one string; this one streams a
# twenty-thousand element array the way kq does — each element into its own
# builder, written, and dead before the next — so the recursion carries the
# whole list and a write chain that grows with it.
#
#
# That shape is what makes kq's flat-array print quadratic: the survival check
# on the carried description walks the list once per element, so the work grows
# with the square of the array's length while every counter below holds still.

# moves none of them — which is the reason this benchmark also has a row in
# bench/instructions_golden.txt, where the cost is visible.
