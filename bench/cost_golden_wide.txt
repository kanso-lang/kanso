# benchmarks beside it has. They carry deeply nested documents whose widest
# array holds ten elements, and they render one string; this one streams a
# sixteen-thousand element array the way kq does — each element into its own
# builder, written, and dead before the next — so the recursion carries the
# whole list and a write chain that grows with it.
#
# That shape is what made kq's flat-array print quadratic, twice over. The
# survival check on the carried description walked the list once per element,

# that allocates nothing and a copy that lands in a buffer both leave these
# figures alone. The row that sees them is in bench/instructions_golden.txt.
