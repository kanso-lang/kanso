# What the compiler wrote for the decoder, counted from jsonbench.ll before
# the linker touches it — so this is deterministic and, unlike a timing, blind
# to code layout.
#
# The decode cost golden beside this one counts what the program ALLOCATES at
# run time. Nothing counted what was EMITTED for it: between 2026-07-27 and
# 2026-08-07 the decoder gained 20% more calls and 23% more branches while its
# allocation counts stayed byte-identical.
#
# That growth is not the cause of the 7.6% slowdown over the same window. The
# code grew while the time held flat and the time rose while the code did not.
# Two dimensions, both worth watching, neither explaining the other.
#
# A rise here is a regression to explain; a fall is a win to bank. Either way
# say which in the PR and regenerate.
#
# 2026-08-08: calls 2346 -> 2350 and lines 13329 -> 13338. Every constant cell
# is seeded with a blackhole before `k_caf_init` runs a builder, so a constant
# that names itself loads a cell rather than the zeroed global — which is an
# integer zero and was being printed as one. The decoder has four such cells:
# four calls and four stores, once, before main. Nothing in a decode loop
# moved, and defines and branches are unchanged.
#
# These are CI's numbers. `lines` carries a small host difference — a macOS
# build of the same source writes two more than the linux runner — so
# regenerate from the failing CI diff rather than from a local run, the way
# the instruction golden already says to.
#
# 2026-08-09: defines 250 -> 154, calls 2350 -> 1660, branches 1311 -> 1018,
# lines 13338 -> 10529. A fall, and a deliberate one: a program with an entry
# now drops any define no remaining line names, to a fixpoint — the rule that
# already pruned unused declares, applied to definitions. What went is the
# whole of text/trim's chain, most of io, and the wrappers only those named:
# a fifth of the file, for a program that decodes json and prints a number.
# A library keeps everything, because its callers are outside the module.
# The binary does not change — -flto already internalised and stripped these,
# __TEXT is 114,688 either way. What is saved is writing them and reading them.
# 2026-08-24: lines 11588 -> 11595. std/text gained `to_bytes`, which the bytes
# gavel required ship beside the coercion's removal, and the decoder imports
# std/text. Seven lines of module-level global for a function it never calls —
# the same shape the os split measured in the other direction. defines, calls
# and branches do not move.
# 2026-08-26: calls 1775 -> 1777, branches 1175 -> 1176, lines 11585 -> 11574.
# Two causes, pulling opposite ways. The own-origin guard puts one declare and
# three `k_not_own_err` calls into the decoder — the arms that can now be
# skipped ask before they match. Against that, `lib/json` shed the `defect`
# record, and a record that goes takes its name out of the string table and its
# arm out of the field dispatch: six string constants and one call with it. The
# defines count does not move, because `defect` was a type rather than a
# function and `must` was already dead when #1034 stopped calling it.
# 2026-08-26: calls 1777 -> 1785, branches 1176 -> 1168, lines 11574 -> 11527.
# The register-returnable construction stopped bailing on its first failing
# field. It used to test the position, return if that failed, then test the
# value and return if THAT failed — two tests, two branches, two exits. It now
# tests both and calls `k_pair_failure` once on the merged path, which is one
# branch and one call where there were two branches. Eight sites in the
# decoder: eight calls gained, eight branches shed, and the second bail block
# at each site is gone, which is where the forty-seven lines went. The change
# is a correctness fix — native and wasm handed back the FIRST failing field
# where the interpreter merged both reasons — and the code came out smaller.
# 2026-09-02: +2 defines, +4 calls, +6 branches, +53 lines. The two inline
# dispatcher twins, arity one and arity two. The decoder writes fifteen call
# sites for them and reaches none of them from its entry, so its `.text` is
# byte-identical and its instruction row does not move: the twins are counted
# here, written, and then dropped by the linker.
# 2026-09-02 (later): +2 defines, +3 calls, +3 branches, +49 lines — the two
# inline record twins, `k_check_rec_fast` and `k_field_fast`. The decoder
# writes 134 sites for them across the ten programs and reaches none of its own
# from its entry, so once again this vein counts the definition and `.text`
# counts nothing.
# 2026-09-02 (later still): six more defines, seven more calls, eight more
# branches and 117 more lines, here and in the other file. Six bit builtins
# gained inline twins in DECLARES, the way the record twins above did. The
# decoder does no bitwise work at all and still carries the six definitions,
# because DECLARES is written whole; the linker drops them and its `.text` is
# byte-identical.
# 2026-09-02 (later): one define, two calls, three branches and thirty-nine
# lines everywhere, for the demanded-index twin. The decoder's own `.text` does
# not move: it indexes bytes and strings, and the twin it now carries is
# unreachable from its entry.
# 2026-09-03 (a number's bytes are read once): one define fewer, twenty more
# calls and 89 more lines, in the decoder and in oneshot beside it. The json
# library used to walk a number twice — `number_end` to find where it stopped,
# `mark_from?` over the same bytes to decide float or int — and the mark rides
# the single scan now. Two small walkers became one larger one with an extra
# argument, which is why the line count rises while the work falls: jsonbench
# retires 4.14% fewer instructions for it. `branches` does not move.
# 2026-09-03 (a byte switch on the byte): eight calls, twenty-four branches
# and eighty lines fewer in the decoder, and the same shape in the four
# programs beside it that dispatch on bytes. A group whose discriminator
# crossed as a raw i64 had that i64 rebuilt into a KValue for the dispatch

# branches this drops are the tag test and the none test the tree wrote per

#
# 2026-09-05 (slice takes four scalars through a shim): +1 define, +2 calls,
# +1 branch, +25 lines, in every program whether it slices bytes or not. That
# is the prelude twin: the emitter writes it once per module and the linker

# .text rows grew. The find2 shim before it cost the same shape.
#
# 2026-09-05 (third): one more prelude twin, `k_b_utf8_slice_fast`, and the
# same shape a third time — +1 define, +2 calls, +1 branch, +25 lines here and

# calls the builtin or not; only jsonbench and oneshot grew any machine code

#
# 2026-09-05 (fourth): a fourth prelude twin, `k_b_find2_below_fast`, and the
# same shape again — +1 define, +2 calls, +1 branch, +35 lines per module. The
# emitter writes it whether the program calls the builtin or not.

# 2026-09-05 (fifth): branches 1,163 -> 1,171 and lines 12,134 -> 12,188 — the
# in-place append's copy became a width ladder, four conditional branches

# 2026-09-05 (sixth): calls 1836 -> 1828, and not one instruction of emitted
# code changed. The counter was `grep -c 'call '` over the whole .ll, so the
