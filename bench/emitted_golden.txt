# What the compiler wrote for the decoder, counted from jsonbench.ll before
# the linker touches it — so this is deterministic and, unlike a timing, blind
# to code layout.
#
# The decode cost golden beside this one counts what the program ALLOCATES at
# run time. Nothing counted what was EMITTED for it: between 2026-07-27 and
# 2026-08-07 the decoder gained 20% more calls and 23% more branches while its
# allocation counts stayed byte-identical.
#
# That growth is not the cause of the 7.6% slowdown over the same window. The
# code grew while the time held flat and the time rose while the code did not.
# Two dimensions, both worth watching, neither explaining the other.
#
# A rise here is a regression to explain; a fall is a win to bank. Either way
# say which in the PR and regenerate.
#
# 2026-08-08: calls 2346 -> 2350 and lines 13329 -> 13338. Every constant cell
# is seeded with a blackhole before `k_caf_init` runs a builder, so a constant
# that names itself loads a cell rather than the zeroed global — which is an
# integer zero and was being printed as one. The decoder has four such cells:
# four calls and four stores, once, before main. Nothing in a decode loop
# moved, and defines and branches are unchanged.
#
# These are CI's numbers. `lines` carries a small host difference — a macOS
# build of the same source writes two more than the linux runner — so
# regenerate from the failing CI diff rather than from a local run, the way
# the instruction golden already says to.
#
# 2026-08-09: defines 250 -> 154, calls 2350 -> 1660, branches 1311 -> 1018,
# lines 13338 -> 10529. A fall, and a deliberate one: a program with an entry
# now drops any define no remaining line names, to a fixpoint — the rule that
# already pruned unused declares, applied to definitions. What went is the
# whole of text/trim's chain, most of io, and the wrappers only those named:
# a fifth of the file, for a program that decodes json and prints a number.
# A library keeps everything, because its callers are outside the module.
# The binary does not change — -flto already internalised and stripped these,
# __TEXT is 114,688 either way. What is saved is writing them and reading them.
