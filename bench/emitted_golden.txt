# What the compiler wrote for the decoder, counted from jsonbench.ll before
# the linker touches it: deterministic, and blind to code layout.
#
# The decode cost golden beside this one counts what the program allocates at
# run time. The two move independently: the decoder once gained 20% more calls
# and 23% more branches while its allocation counts stayed byte-identical.
# Watch both, and assume neither explains the other.
#
# `defines` and `branches` match at the start of a line. `calls` is counted
# with comment lines stripped, so rewording a comment cannot move it. `lines`
# counts the whole file, comments included.
#
# Every module carries the whole prelude of inline twins whether it calls them
# or not, so a twin added there moves every row here and in
# emitted_golden_others.txt by the same amount, while the linker drops what
# nothing reaches and `.text` need not move.
#
# These are CI's numbers. `lines` differs by host (a macOS build of the same
# source writes two more), and the whole file differs by the clang the
# compiler probes: under clang 18 there is no `preserve_none` and the emitter
# writes another convention. Take the rows from the failing CI diff.
#
# A rise is a regression to explain and a fall is a win to bank: say which in
# design/compiler-log.md, which holds the history of every move, and
# regenerate.
