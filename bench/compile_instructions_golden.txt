# moves where the rehashes land, so the count was not a repeatable quantity.
# Same binary, same sources, same directory, empty environment:
#
#   default hasher   90,704,760   90,676,800
#   seedless hash    66,961,255   66,961,255   66,961,255

# Forty thousand instructions of spread against nothing to explain it. The
# compiler hashes its own maps with a seedless hash now, and three runs give
# the same digits.

# MEASURED IN A BOX. The count moves with the length of the directory the
# compiler runs in — 5,613 instructions across 35 characters, about 160 each,

# row would pin the clone, which is the reason compile_alloc_bytes is absent
# from its own golden rather than pinned in it. The gate copies lib/ to a
# fixed path and compiles from there, so two clones at different depths agree

#
# The row belongs to the toolchain that built the binary and to the libc that
# serves its malloc and its memcpy, so it names both and
# scripts/gates/measured_on.sh refuses to read it anywhere else.
#
# A rise is a regression to explain and a fall is a win to bank. Movement is
# fine; silence is not.

# ONE ROW, ONE VALUE, ruled 2026-09-05. This file held a bare number for the
