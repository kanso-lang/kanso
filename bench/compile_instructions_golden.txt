# Retired instructions for `kanso check compile_corpus`, counted under
# callgrind and anchored at `kanso::main` inclusive, which is past Rust's stack
# guard and the loader. This counts the compiler: bench/instructions_golden.txt
# counts the programs it produces. The front end once fell by a quarter with
# every other gate in the tree reporting nothing, which is why this row exists.
#
# The compiler hashes its own maps with a seedless hash. std's default hasher
# carries a per-process random key, and with it two runs of one binary read
# forty thousand instructions apart; with the seedless hash they agree to the
# digit.
#
# Measured in a box. The count moves with the length of the directory the
# compiler runs in, about 160 instructions a character, because the absolute
# path is copied and walked. The gate stages the corpus at a fixed path and
# compiles from there.
#
# One row, one value, ruled 2026-09-05: the same build counts the same number
# on any runner. A run that disagrees is a reproduction failure. It halts this
# vein and is hunted to its source, never written down beside the value it
# disagreed with.
#
# EXCLUDED, because neither can be normalized:
# - `std::io::stdio::_print` inclusive. `kanso check` prints one line when it
#   finishes, and the memrchr LineWriter runs over it moves with the binary's
#   layout: builds of identical compiler source drew two values thirteen
#   apart. Not printing costs more than it saves, because a variable or an
#   argument that asks for quiet changes the process the gate measures.
# - `<std::fs::ReadDir as Iterator>::next` inclusive. The corpus is a
#   directory, and the order readdir hands its entries back differs between
#   filesystems; the row alternated by three on one tree until it was left
#   out.
# The gate subtracts both subtrees and prints each as a notice.
#
# The row belongs to the toolchain that built the binary and the libc that
# serves its malloc and memcpy, both named on the last line of this header,
# and the gate refuses any other host. Copy the row from CI's job log. A
# figure from a plain `kanso check` in a checkout differs from this row, and
# should: this one is measured in the box with the environment emptied.
#
# A rise is a regression to explain and a fall is a win to bank: say which in
# design/compiler-log.md, which holds the history of every move. An edit to
# the compiler's Rust usually moves this row by layout alone.
# measured-on glibc=2.39-0ubuntu8.9 rustc=1.98.1
