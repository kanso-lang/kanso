# WHAT THE COMPILER SPENDS EMITTING, counted at the frame that does it.
#
# `kanso::codegen::emit_ir` inclusive, over `kanso build pkg/codegen_corpus`
# in the staged box, read by scripts/gates/emit_instructions.sh.
#
# WHY THE ROW EXISTS. The three `kanso check` rows stop before codegen. The
# two codegen rows count the child tree — the clang driver, the convention
# probe's clang, `clang -cc1` and `ld` — with kanso's own process excluded,
# because it waits for a child and a loop whose iteration count belongs to the
# scheduler is external state. Between the two sat the work this project
# wrote, and nothing counted it.
#
# WHY THE ANCHOR IS EXACT. Measured 2026-09-17 on this project's container,
# four profiles: two readings of the shipped binary and two of a probe binary
# whose `pid_tag_of` returns a constant. Every one read the frame at
# 394,910,642 inclusive, byte for byte, while the process around it moved 233
# and then 112. That number is a CONTAINER's and is written here as evidence
# of the anchor's determinism, never as the row: only CI's numbers may be
# recorded, which is what scripts/gates/measured_on.sh exists to enforce.
#
# The frame is 92.78% of what kanso's own process spends on a release build,
# so what the codegen rows' exclusion drops is the wait and very little else.
#
# HOW IT MOVES. Any change to the emitter moves it, and so does a change to
# the program it is emitting — `pkg/codegen_corpus` is the subject and its own
# size is part of the row. A change under `lib/` moves it too, because
# `lib/*.kso` is `include_str!`'d into the compiler.
#
# THE ROW IS EMPTY ON PURPOSE. This gate ships before its first CI sitting, so
# the gate refuses with the number it measured printed above the refusal. The
# sitting that follows writes the value and the measured-on line under it.
#
# The measured-on line is written beside the first value, by the sitting that
# produces it. There is deliberately none here: a line shaped like neither a
# field list nor prose is the trap measured_on.sh's own header describes.
