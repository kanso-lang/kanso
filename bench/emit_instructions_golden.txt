# two codegen rows count the child tree — the clang driver, the convention

# The frame is 92.78% of what kanso's own process spends on a release build,

# HOW IT MOVES. Any change to the emitter moves it, and so does a change to
# the program it is emitting — `pkg/codegen_corpus` is the subject and its own
# size is part of the row. A change under `lib/` moves it too, because
# `lib/*.kso` is `include_str!`'d into the compiler.
